\ Design system v0.1, rough draft

Light is the only color.

Foundations, principles and guidelines for the college tech committee website. Black surfaces, spectrum light, loud type.

\ Principles

Five rules.

  1. Light is the only color.

    Surfaces stay black and off-white. Spectrum color appears only as light: beams, glows and one accent action. If something is colored and isn't glowing, question it.

  2. Black is a stage.

    Beams move behind. Content holds still in front. Nobody should have to chase text through motion.

  3. Type does the heavy lifting.

    Big uppercase headlines and small mono labels carry the identity, so layouts can stay simple and mostly empty.

  4. Open to every student.

    Readers range from first-years to sponsors and faculty. Plain words, high contrast, no gatekeeping jargon.

  5. Spectacle has a budget.

    One big light moment per page. Every animation has a still fallback and a lighter version for weak phones.

\ Color

Black stage. Spectrum light.

Neutrals do 95% of the work. The spectrum comes straight from the reference beams: cold ion blue, hot ember orange, white cores, and violet and rose fringes. Ratios on each swatch are measured against Void.

Spectrum stays under about 5% of any screen. It should feel rare enough to look bright.

Approved pairings

  • Ultraviolet is a fill and a glow, never small text. It reads at 3.9:1 on Void, so it works for shapes and large UI but fails as body copy. Links use Ion.
  • Rainbow gradients belong to beams and the strip above. Never across text, never as a card background.
  • Color never carries meaning alone. Pair every success, warning or error color with words or an icon.

Draft v0.1
  • Uppercase for headlines and labels only. Write copy in sentence case and let CSS do the capitals, so screen readers and translations behave.
  • Paragraphs stay sentence case. The reference sets whole paragraphs in caps. It looks striking but slows reading, so we keep that for one-line statements.
  • Section marker. A backslash and a mono label sets each section apart (see the labels on this page). Use it for wayfinding, not decoration.
  • Left-aligned, ragged right. Never justify. Center only single-line moments.
  • Line length. Body copy stays under 65 characters per line.

\ Spacing and layout

Mostly empty, on purpose.

Light needs darkness around it. Generous space makes the beams and the headlines feel bigger.

Spacing scale, 4px base

    Editorial split on a 12-column grid

    Label
    cols 1 to 2
    Headline, uppercase display
    cols 3 to 8
    Body and action
    cols 9 to 12
    • Grid. 12 columns, 24px gutter (16px under 768px), side margins 20 to 64px, content max width 1440px.
    • Breakpoints. 480, 768, 1024, 1280, 1536. Design mobile first; the beam layer shrinks before the layout does.
    • Section rhythm. 96px between sections on desktop, 64px on mobile. Use 1px hairlines to separate, not boxes.
    • Alignment. Left aligned. Labels sit left, headlines in the middle, supporting copy on the right.

    \ Shape, depth, icons

    Sharp edges. Soft glow.

    Corners are square and borders are hairlines. Depth comes from light spilling out of an element, never from a grey drop shadow.

    Hairline1px, white at 12%. Default separation.
    Glow / IonFocus, active, live states.
    Glow / UltravioletThe single key action on a screen.
    • Radius. 0 for everything. The only round shapes are status dots and avatars (--radius-pill).
    • Glow budget. At most one glowing element per viewport, except beams.
    • Grain. A faint 6% film grain sits over the whole page, taken from the black reference. It stops big black areas looking flat.

    Icon style

    24px grid, 1.5px stroke, square caps, mitered joins, no fills. Sizes 16, 20, 24, 32. Color: Photon, or Ion when active. Draw custom icons to match, or use an open-source set with the same stroke.

    \ Motion

    Light moves. Content doesn't.

    Beams have three speeds. The same engine drives the hero above and the demo below. Try each state.

    State idle, speed 0.12

    StateUse it for
    Idle, 0.12Default ambient background. Slow drift you barely notice.
    Cruise, 0.45Responding to an action: hovering the main call to action, scrolling a hero.
    Warp, 2.0Page transitions only, up to 1.2s, then back to idle. Never on load, never repeated.
    TokenValue and use
    --dur-instant90ms. Press feedback.
    --dur-fast160ms. Hover, color change.
    --dur-base280ms. Open, close, expand.
    --dur-slow560ms. Reveals and large elements.
    --dur-scene1200ms. Page transition with warp.
    --ease-snapcubic-bezier(.2,.8,.2,1). Default for interface motion: quick start, soft landing.
    --ease-warpcubic-bezier(.7,0,.3,1). Speed changes and transitions.
    --ease-beamlinear. Beams only; light doesn't ease.

    Beam recipe

    • Origin. One vanishing point, placed off-center so text has room. Streaks fly outward.
    • Mix. About 26% ion, 22% ember, 20% white, 12% ultraviolet, 10% plasma, 6% rose, 4% amber.
    • Render. Additive blending, a wide soft stroke under a thin bright core, brighter and thicker as they near the edge.
    • Cost. About 240 streaks on desktop, about 110 on phones, pixel ratio capped at 2.

    Rules

    • Ambient motion is slow; responsive motion is fast.
    • One orchestrated moment per page. No scattered fade-ins on every block.
    • Always pausable. A visible pause control, and beams stop when off-screen or the tab is hidden.
    • Reduced motion means a still frame, not a blank background.

    \ Accessibility

    Readable over anything.

    Bright beams are the biggest legibility risk in this concept. Text never sits on raw light.

    • Contrast. Body text 4.5:1 or better, large text and UI shapes 3:1. Photon on Void is 18.6:1; keep Dim for text of 14px and up.
    • Scrims. Any text over the beam layer gets a Void gradient behind it at 70% or more opacity where the text sits.
    • Focus. 2px Ion outline with 3px offset on every interactive element. Never remove it.
    • Motion. Respect prefers-reduced-motion. Nothing flashes more than 3 times per second; beams stream, they don't strobe.
    • Touch targets. At least 44 by 44px.
    • Not by color alone. Status uses color plus a word or icon.
    • Small mono labels. Minimum 12px, always with the extra tracking, never Dim on a lighter surface.

    \ Voice and tone

    Short, direct, welcoming.

    Direct

    Say what happens, when and where. Lead with the fact.

    Welcoming

    A first-year should feel invited, not tested.

    Technical, not gatekeeping

    Use real terms, explain them once, never sneer at beginners.

    Energetic, not shouty

    The type is already loud. The words can be calm.

    \ Quick check

    Do. Don't.

    Do

    • Keep the reading area dark and push the brightest light to the edges.
    • Use Photon for text and spectrum only for light.
    • Give each screen one Ultraviolet action.
    • Set headlines in uppercase display and paragraphs in sentence case.
    • Ship every animation with a still fallback.

    Don't

    • Put text on a bright beam without a scrim.
    • Fill cards or large surfaces with spectrum color.
    • Run a rainbow gradient through text.
    • Add rounded corners, grey drop shadows or white surfaces.
    • Flash, strobe or loop warp speed.
    • Set paragraphs in all caps.

    \ Still open

    To decide next.

    • Committee name and logo. The wordmark in the header is a placeholder.
    • Fonts. Confirm Inter Tight, Inter and JetBrains Mono, or pick closer matches to the reference.
    • Primary accent. Ultraviolet is proposed. Ion is the alternative.
    • Hero engine. This draft uses a 2D canvas. WebGL would allow richer bloom at a higher performance cost.
    • Next phase. Components and page patterns, once this direction is approved.
